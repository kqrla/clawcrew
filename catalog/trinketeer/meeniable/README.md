# meeniable

Custom collector figures. The first line, and the only one that is live.

Four styles, one production path: a style is a model variant, not a separate business. Sharing the path is
the point, since the fixed cost (printing, finishing, packaging, the storefront) is the same for all four.

| style | status | note |
| --- | --- | --- |
| [funko-pops](funko-pops/README.md) | live | v1: everything built so far |
| [bondee-dolls](bondee-dolls/README.md) | planned | soft proportions |
| [block-type](block-type/README.md) | planned | blocky, minecraft-adjacent |
| [mino-girl](mino-girl/README.md) | planned | fourth style |

The line's objective is `obj.trinketeer.meeniable.revenue`; each style gets its own objective when it moves
past `planned`, because a style that cannot be measured is a style nobody should be building.
