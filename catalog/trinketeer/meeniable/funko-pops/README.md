# funko-pops (v1)

The line the support slice, the evidence rules, and the storefront were all built against. Its metric is paid
orders, sourced from Stripe, and its work kinds are `support` and `code`.

Historical note: this line was called "figures" before the company was named, and `meenible` before the
company was renamed. Those names survive in the ledger as retired objectives rather than being rewritten
(`docs/45`, `docs/54`), because a version that changes meaning is a lie about every row that cited it.
