# skeleton

a starting point, not an implementation. every file here is a contract with a
question attached: what must be true, what may never happen, what proves it.

nothing is copied from another project. the shapes come from
[the design notes](../design-orchart-design-notes-v0.1.md) and from the specs in
[../docs](../docs), written fresh so the reasoning travels with the code.

order to fill them in: authority, tier, ledger, scheduler, relay, convergence, skills.
each one depends on the one before it, and none of them needs a model to run.
