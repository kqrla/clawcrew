# docs

one idea per document, numbered, in the order the concepts arrived. each one names what it refuses,
because a document that only describes what something does is a manual, and a manual cannot be
checked.

| # | document | the idea |
| --- | --- | --- |
| 26 | on-call as a lease | responsibility expires and returns; a calendar entry does not |
| 27 | reservations | spend is approved before the work, not discovered after |
| 28 | handoff acceptance | a handoff is accepted or bounced with a reason; silence is not acceptance |
| 29 | slice ontology | a slice is a vocabulary, an evidence grammar, and a set of contracts |
| 30 | project lifecycle | a business moves through seven phases, and a phase moves on rows |
| 31 | measurement | a source is a promise; a reading is a measurement |
| 32 | corroboration | one number, two expressions, different hands |
| 33 | the auditor | a third answer from outside the org, weekly, on alerts that close only on evidence |
| 34 | agent lifecycle | duplicable, freezable, thawable, burned, and what each refuses |

the folder map, including the non-technical folders, is [`../readme-structure.md`](../readme-structure.md).
